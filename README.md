# ⚡ NEON DASH

> لعبة ركض لانهائي (Endless Runner) سريعة الإيقاع بطابع السايبربانك (Cyberpunk)، مبنية بالكامل باستخدام Vanilla JavaScript و HTML5 Canvas.

## 📖 القصة
مرحباً بك في شوارع عام 2084 المضاءة بالنيون. أنت عدّاء هارب في مدينة "سايبربانك" لا ترحم. ابقَ على قيد الحياة وتجاوز العقبات اللانهائية، اجمع عملات الطاقة، وفعّل نظام الـ "Overdrive" الخارق لتحطيم الحواجز. إلى أي مدى يمكنك الركض قبل أن تلحق بك المدينة؟

## 🎮 أزرار التحكم (لوحة المفاتيح)
* **[ SPACE / مسطرة ]** : القفز (Jump)
* **[ SHIFT ]** : الاندفاع (Dash - اندفاع سريع للأمام لتخطي العقبات المتقاربة)
* **[ E ]** : أوفر درايف (OVERDRIVE - يتطلب طاقة كاملة، يجعلك لا تُقهر، يزيد سرعتك، ويحطم العقبات بلمسة واحدة!)
* **[ P ] أو [ ESC ]** : إيقاف اللعبة مؤقتاً (Pause)

## ✨ المميزات الأساسية
* **محرك فيزياء مخصص:** ميكانيكيات قفز، اندفاع، وجاذبية سلسة ومبنية من الصفر (بدون محركات ألعاب جاهزة).
* **نظام التقدم (Progression):** اقتصاد متكامل لجمع العملات وفتح شخصيات (Skins) مميزة، أو تحقيق أرقام قياسية لفتح السكنات الأسطورية.
* **الإنجازات والمهمات (Achievements & Missions):** تتبع حي للمهمات وتحديات مستمرة مع نظام إشعارات (Toasts) تظهر داخل اللعبة عند إنجازها.
* **تطبيق ويب تقدمي (PWA):** تدعم التثبيت على الأجهزة واللعب بدون اتصال بالإنترنت (Offline) بفضل نظام الـ Service Workers.
* **أداء عالي وبدون مكاتب خارجية (Zero Dependencies):** مبنية 100% باستخدام Vanilla ES6 JavaScript، HTML، و CSS.

## 🛠️ التقنيات المستخدمة
* **HTML5 Canvas API:** لرسم اللعبة (Rendering) وإدارة الـ Game Loop.
* **Vanilla JavaScript (ES6 Modules):** هيكلة برمجية نظيفة وكائنية التوجه (OOP).
* **CSS3:** لتصميم واجهات السايبربانك، الألوان المضيئة (Neon Glow)، وحركات الواجهة.
* **Web Audio API:** توليد جميع المؤثرات الصوتية برمجياً بأسلوب الـ 8-bit (لا يوجد ملفات صوتية خارجية مسجلة).
* **LocalStorage:** نظام حفظ آمن ومستمر لتقدم اللاعب وإنجازاته في المتصفح.
* **Service Workers:** للكاشينج (Caching) وإدارة اللعب بدون إنترنت.
